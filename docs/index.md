# TerrainLayers and TerrainGenerator for Terrain3D

Companion tools for [Terrain3D](https://github.com/TokisanGames/Terrain3D): multi-texture **layers** and a procedural **generator**.

## Requires

- Godot 4.x
- Terrain3D 1.1.x (install and enable first)
